# Security Policy / Güvenlik Politikası

## Supported versions / Desteklenen sürümler

Only the latest release receives fixes. / Yalnızca son sürüm düzeltme alır.

## Privacy by design / Tasarımdan gelen gizlilik

SysMon makes **no network connections**, collects **no data**, and needs **no special permissions**. It reads standard system statistics (CPU, memory, disk, battery, process list) locally.

SysMon **hiçbir ağ bağlantısı kurmaz**, **veri toplamaz** ve **özel izin gerektirmez**. Standart sistem istatistiklerini (CPU, bellek, disk, pil, işlem listesi) yerelde okur.

## Reporting a vulnerability / Güvenlik açığı bildirme

Please **do not** open a public issue for security problems. Use GitHub's private reporting instead:

Güvenlik sorunları için lütfen herkese açık issue **açma**. Bunun yerine GitHub'ın özel bildirimini kullan:

➡️ [Report a vulnerability / Açık bildir](https://github.com/ozkurtomer/sysmon/security/advisories/new)

You'll get a first response within a few days. / Birkaç gün içinde ilk yanıtı alırsın.
